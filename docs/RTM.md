## Deferred (Tier 3) — explicitly out of scope for `complete-app-trial`

These were in the original detailed flow spec but are not implemented, and are not silently dropped — they need real infrastructure this trial doesn't have:

- **Live GPS tracking.** "I'm coming" (FR-05) is a manual boolean flag the driver toggles, surfacing the ride's already-known distance/estimate — not a live map position. Real tracking needs a location-streaming pipeline (background location permission handling, a live-position channel, battery/privacy tradeoffs) that's a project of its own.
- **Push notifications.** Every list in the app (Requests badge, Home, Activity) is refreshed by polling on navigation, not pushed. Real push needs FCM (or equivalent) wired through both the backend and a Google/Firebase project registration, which hasn't been set up.
- **Allocate+ calendar sync** (FR-06) — blocked on Allocate+ API access, same as before this rework.
- **Email-based account features** — email verification and self-service password reset need the backend to send email, which isn't set up.
